# Vitrine de Produtos — Teste Front-End Econverse

## Sobre o projeto

Projeto de uma vitrine de produtos desenvolvido como parte do teste técnico para a vaga de Front-End Júnior da Econverse.

A aplicação apresenta produtos em cartões, permite pesquisar produtos pelo nome e visualizar seus detalhes em um modal.

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- Sass (SCSS)
- CSS Modules

## Funcionalidades

- Exibição de produtos em cartões.
- Busca de produtos pelo nome ou descrição.
- Modal com informações detalhadas do produto.
- Layout responsivo para diferentes tamanhos de tela.
- Formulário demonstrativo de newsletter.

## Como executar o projeto

### Pré-requisitos

- Node.js
- npm

### Instalação

Clone o repositório e entre na pasta do projeto:

```bash
git clone URL_DO_SEU_REPOSITORIO
cd vitrine-front
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Observações

Os dados dos produtos estão definidos localmente no projeto. O formulário de newsletter é demonstrativo e não envia os cadastros para um servidor.
